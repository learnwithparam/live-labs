# Code of conduct

1. Critique the work, not the person. Say what you would change and why.
2. Help first. If you know the answer to an open question, answer it before posting your own.
3. No recruiting, selling or cold outreach in threads.
4. Never post secrets, customer data or code your employer has not cleared. Leaders: remove company and
   people names from playbooks and charters.
5. Say where an idea came from. Link the repo, post or person.

Breaking these gets a post hidden, then the account blocked from this repo. Report a post with GitHub's
"Report content" menu or by email to support@learnwithparam.com.
