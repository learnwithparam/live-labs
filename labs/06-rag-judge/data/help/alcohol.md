# Delivering alcohol

## Checking ID

Scan the ID of the person receiving an alcohol order in the app. The person must be 21 or older, must be the customer named on the order, and must not appear intoxicated.

## When you cannot deliver

If no valid ID is shown, or the person appears intoxicated, do not hand over the alcohol. Return it to the store the same day; you are paid the full base pay plus $5 for the return trip.
